ZenkeiViewer
===============
ZenkeiViewerはデスクトップ向けの360度画像ビューワーです。

操作方法
============

ファイルを開く
-----------------
次のいずれかの方法でファイルを開くことができます。

- コマンドラインからファイル名もしくはフォルダ名を指定する
- メニューの File -> Open を選択する
- ファイルをウィンドウにドラッグアンドドロップする

対応する画像ファイルの形式は、JPEG、PNG、WebP、BMP、AVIF です。

画像ファイルを開いたあと、ウィンドウの左右端の矢印ボタンをクリックするか、キーボードでAlt+左右矢印キーを押すと、同じフォルダ内の前後の画像に切り替えることができます。

メニューや左右端の矢印ボタンは、操作を行うと数秒間表示され、その後自動的に消えるようになっています。

画像の表示
-----------------
360°画像である情報がついているファイルを開くと、自動的に360°画像として表示されます。
それ以外の画像は通常の2D画像として表示されます。
切り替えは View -> Panorama (360° Spherical) か View -> Flat (2D) メニューで行うことができます。

360°画像の表示の場合はマウス左ドラッグで回転、マウスホイールでズームが行えます。
普通の左ドラッグの場合は上下左右に回転しますが、Shiftキーを押しながら左ドラッグすると傾き方向の回転になります。
またShiftキーを押しながらマウスホイールを回すと、ズームではなく画角の変更になります(歪み具合が変わります)。

タッチ操作の場合は一本指ドラッグで回転、ピンチでズームが行えます。
二本指で回転させると傾き方向の回転になります。

2D画像表示の場合は、マウス左ドラッグ/一本指ドラッグで画像を移動、マウスホイール/ピンチでズームが行えます。

視点のリセットは View -> Reset メニューか、キーボードの R キーで行うことができます。
